# Nobre Flipbooks

Biblioteca estática para GitHub Pages.

## Primeira publicação

`atlas-das-brumas/` — aplicação interativa da campanha veterana *Poderes Sombrios* (Lloyd, Aunilan, Kaelion, Ireena, Valerius).

- Navegação por páginas, índice e visualizações responsivas.
- Sete Domínios do Pavor, sem revelações de Mestre.
- Formulário com salvamento **local** no navegador.
- Exportação de TXT, cópia e impressão/PDF no navegador.
- Nenhum backend, coleta ou envio automático de respostas.

## Publicar

Envie os conteúdos desta pasta para a raiz do repositório `robertonobre22/flipbooks`. Ative Settings > Pages > Deploy from a branch > main > /(root).

O endereço esperado depois do deploy é `https://robertonobre22.github.io/flipbooks/`.

## Segurança

Tudo aqui é público. Não inclua segredos do Mestre ou dados privados de jogadores. O salvamento local pode se perder ao limpar os dados do navegador ou usar outro dispositivo.
